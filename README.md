# deep-learning-experiments
深度学习基础实验，基于 PyTorch 从零实现

项目目的
验证卷积神经网络在图像分类任务上的效果，练习完整训练流程，测试不同结构/超参对性能的影响。

实验环境
- Python 3.9
- PyTorch 2.0
- 数据集：CIFAR-10

实现内容
- 手动搭建2层卷积+2层全连接的CNN模型
- 完整训练/验证循环，准确率与损失计算
- 对比实验：不同学习率、是否加入Dropout的效果差异

实验结果
| 实验配置 | 测试集准确率 | 现象说明 |
|---------|------------|----------|
| 基线模型 lr=0.01 | 72.3% | 后期明显过拟合 |
| 加入Dropout lr=0.01 | 75.1% | 过拟合得到缓解 |

踩坑与总结
1. 初始学习率设为0.1导致训练震荡 → 下调到0.01后稳定收敛
2. 训练集准确率远高于测试集 → 加入Dropout和数据增强后泛化性提升

文件说明
- train.py：主训练代码
- model.py：模型定义
- results/：存放实验结果图
